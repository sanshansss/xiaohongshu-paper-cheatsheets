## 保存方式与范围

- 保存日期：**2026-10-07**。
- 方式：在浏览器中直接查看作者主页及各帖子后保存帖内展示图片，**未调用小红书数据接口或爬虫**。
- 每条帖子单独一个文件夹，图片按 `01.webp`、`02.webp` 顺序保存，并附 `帖子信息.txt`（标题、原帖链接、保存日期、话题标签）与 `清单.json`（图片尺寸、字节数）。
- 图片为网页实际提供的 **WebP** 文件，保持下载所得字节，**不代表作者的源文件，也不是平台可提供的最高分辨率**。
- 所有图片均已通过解码完整性检查，无下载失败。
- 范围为本次浏览器主页加载并浏览到的 **62** 条不同帖子；排除了日常、读博周记及录用消息等内容，未访问不可见收藏；未包含作者删除、隐藏或主页未提供的内容。
